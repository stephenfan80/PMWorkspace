# AI 产品工作站 / PMWorkspace v0.1.21

本版本做 eval 分类瘦身和插件发布同步：保持 PMW 业务逻辑不变，只整理维护分类、版本身份和插件包一致性。

## 变化

- Eval 分类地图收口：快速成型 / 深度交付归入 `autoplan`，原型方案旧别名归入 `pm-prototype-shotgun`，出图准备度归入 `readiness-dashboard`。
- 版本、升级检查和插件打包相关 fixture 统一归入 `release-maintenance`，不再继续新增 `versioning` 或 `plugin-release` 分类。
- 三张分类地图保持一致：`pm-workbench-map.md`、`pm-eval-system.md` 和 `evals/README.md`。
- 重新构建 Codex plugin 包，确保 plugin 版本、README、eval fixture 和 shared references 与 source 同步。
