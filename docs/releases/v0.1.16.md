# AI 产品工作站 / PMWorkspace v0.1.16

本版本修复一次真实运行中的严重流程失控：已有功能迭代里，Agent 不能因为用户选择了一个方向并上传截图，就直接生成原型。

## 变化

- 明确 `方案方向确认` 不等于 `产品简报确认`；用户选择方案 A/B/C 后，如果又补充线上截图，必须重新把截图事实写入候选 brief 并等待确认。
- 新增 `线上基线接收` 规则：先拆解当前线上优势、问题区域、必须保留、可以改、暂不应改，以及新方案为什么会优于当前线上。
- Product Readiness Dashboard 新增 `生产基线改动证明` gate：有 `visual_baseline` 时，prototype-board 输出单元必须写明当前线上问题、改动区域、为什么优于当前线上、保留 / 删除边界。
- 视觉基线场景下不再允许默认 `redraw`；已有功能迭代默认走 `screenshot_edit`，从参考截图出发只改目标区域并保护线上保留区域。
- 原型复审增加“是否真的优于当前线上”的判断；如果新图更重、更难扫或破坏线上优势，不能因为看起来新就通过。
