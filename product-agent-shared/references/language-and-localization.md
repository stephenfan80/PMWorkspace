# language and localization

- Use Chinese for Chinese users and product docs.
- Explain risks in product-manager language: product bias, user misunderstanding, review risk, delivery risk.
- Keep necessary technical terms such as PRD, API, URL, image-2, token, and JSON.
- Prefer short status labels: `待补充`、`待确认`、`已对齐`、`可出原型`、`可交付`、`阻断`.
