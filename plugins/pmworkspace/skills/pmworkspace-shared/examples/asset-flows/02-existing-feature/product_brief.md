# product_brief：订阅取消页优化

状态：已对齐
来源：生产截图组 / v1
适用任务：已有功能迭代 -> 视觉基线 -> 截图编辑 / 物理长板原型 -> 交付

## 一句话判断

订阅取消页可以优化，但目标必须写成“减少误取消并提升状态理解”，不能写成“降低取消率”；取消入口仍需清晰可达。

## 推荐方案

1. 保留现有账号导航、订阅信息和取消入口位置。
2. 在取消前增加“暂停 vs 取消”的差异解释，但不新增不可用优惠或人工挽留。
3. 把主按钮文案从模糊动作改为清晰选择：`暂停订阅`、`继续取消`。
4. 确认后结果页说明订阅状态、生效时间和恢复方式。

## 为什么这样做

- 用户问题：用户不理解“暂停”和“取消”的结果差异。
- 当前替代：用户直接点取消，之后再联系客服或重新订阅。
- 当前损失：误取消、客服压力、用户对服务状态不确定。
- 主目标：减少误取消。
- 反指标：取消入口不能被隐藏，取消路径不能变复杂或不合规。

## 原型范围

- 本轮做：取消页优化、取消 / 暂停确认结果页。
- 本轮不做：优惠挽留、人工回访、新计费政策、复杂订阅管理中心。

## 不能虚构 / 不能承诺

- 不展示折扣、优惠券或人工回访。
- 不承诺暂停一定保留价格，除非政策支持。
- 不隐藏取消入口，不把取消按钮弱化到不可发现。
- 不改变账号导航、订阅主体信息和法定取消路径。

## 当前需要确认

无出图阻断项。本轮按以下已确认或已声明假设推进：

- 已提供生产截图，可形成 `visual_baseline`。
- 暂停订阅能力存在，但暂停时长范围仍需业务确认。
- 法定取消入口必须保持清晰可见。
