# AI 产品工作站 / PMWorkspace v0.1.14

This release updates the Codex plugin brand assets.

## Highlights

- Replaces the previous placeholder icon with the selected premium north-star / agent-orbit logo.
- Adds source listing assets at `assets/plugin-listing/icon.png` and `assets/plugin-listing/logo.png`.
- Rebuilds the bundled Codex plugin package so `plugins/pmworkspace/assets/icon.png` and `logo.png` use the new brand mark.

## Update

```bash
codex plugin marketplace upgrade pmworkspace
```

If the local marketplace was installed from GitHub and upgrade is unavailable, run:

```bash
codex plugin marketplace remove pmworkspace
codex plugin marketplace add stephenfan80/PMWorkspace
```
