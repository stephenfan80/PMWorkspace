# PMWorkspace v0.1.37

PMW v0.1.37 is a hotfix for Operation Router adoption in generated skill contracts.

## Changes

- Updates `pmw-gen-skill-docs` so generated SKILL.md shared gates say PMW hits must go through trigger guard and operation router first.
- Removes stale direct-child skill guidance that told `$pm-brief`, `$pm-prototype-shotgun`, `$pm-autoplan`, `$pm-jobs`, `$pm-strategy-review`, and `$pm-handoff` to run intake by default.
- Adds eval coverage to prevent the old "every PMW product task first runs intake" contract from returning.

## Why

v0.1.36 added the runtime Operation Router, but generated skill summaries still carried the old linear intake wording. That allowed small flow-internal actions like prototype revisions to be treated as new workflows by agents following skill docs.
