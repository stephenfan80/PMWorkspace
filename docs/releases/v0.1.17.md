# AI 产品工作站 / PMWorkspace v0.1.17

本版本继续修复真实运行暴露出的体验问题：PMW 不能只根据当前对话片段、一个推荐方向或一次 D 就继续出原型，而要先把分散项目事实收束成统一产品上下文，并在早期对齐中帮助用户补强产品判断。

## 变化

- 新增 `产品信息对齐包`：每个技能开始时先收束已知事实、证据边界、最早门槛、当前最大缺口、用户只需补的一步和补齐后解锁的产物。
- `pmw-dashboard status` 默认展示产品信息对齐状态、当前产品缺口和用户只需做什么，让 Agent 不必分散读取多处状态才能判断下一步。
- `$pm-workspace`、`$pm-autoplan`、`$pm-jobs`、`$pm-brief`、`$pm-strategy-review`、`$pm-prototype-shotgun` 和 `$pm-prototype-review` 都必须读取或建立统一上下文，不能只凭最后一句话继续下游。
- 已有功能迭代缺线上截图、录屏或等价视觉基线时，不能先输出方案 A/B/C、三条产品路径或原型计划；只能输出产品信息对齐卡、证据请求、Agent 拿到材料后的拆解方式和解锁下一步。
- 产品简报新增用户可见 `产品信息对齐卡`，让真实问题、证据边界、当前最大缺口和对抗校验不再藏在内部审计里。
- 新增 eval 覆盖 dashboard 状态摘要、已有功能缺视觉基线不出方案、产品简报前必须先收束产品信息对齐卡。
