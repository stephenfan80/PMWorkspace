# AI 产品工作站 / PMWorkspace v0.1.19

本版本修复产品简报后的真实执行顺序：候选简报生成后先暴露待确认信息和偏差风险，用户补齐或确认假设后才进入已对齐状态；Zoon 同步提醒后置到产品简报已对齐之后。

## 变化

- `$pm-brief` 默认输出 `待确认信息与偏差风险`，逐项说明缺什么、为什么影响判断、不补齐可能导致的产品方案偏差，以及用户现在该补材料、回答 Q、拍板 D 或确认按假设推进。
- `product-manager-brief.md` 模板新增待确认信息与偏差风险区块，避免把关键不确定性藏进普通待验证项。
- `zoon-workflow.md`、`product-plan-handoff.md` 和 `$pm-autoplan` 统一为：待确认简报不询问 Zoon，同步选择只在产品简报确认状态已对齐后出现。
- 更新说明页、README 和 eval，防止回退成“保存本地简报后立即推荐 Zoon”。
