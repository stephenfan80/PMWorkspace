# AI 产品工作站 / PMWorkspace v0.1.27

本版本加固本地 GitHub plugin 的显式升级链路：PMW 不做普通产品流程中的静默升级，但当用户明确要求更新本地 plugin 时，升级脚本必须从配置的 GitHub 源拉包、构建并安装。

## 变化

- `pmw-upgrade --host codex-plugin` 现在会输出 `PMW_UPGRADE_SOURCE <repo_url>`，便于确认本次安装来自哪个 Git 源。
- `pmw-upgrade` 使用 `GIT_TERMINAL_PROMPT=0 git clone`，避免升级时卡在交互认证。
- `update-workflow.md` 明确本地 GitHub plugin 是“显式升级”模式：`pmw-update-check` 只检查和提示，真正安装必须由用户确认后执行 `pmw-upgrade --host codex-plugin`。
- `docs/codex-plugin-submission.md` 补充本地 plugin 用户更新说明，强调从 `repo_url` / `PMW_REPO_URL` 拉取最新 PMWorkspace 源码并重装本地 plugin 包。
- 新增 `local-plugin-explicit-github-upgrade-required` eval，覆盖显式升级、Git 源安装、禁止普通流程静默更新和禁止只复用旧缓存等场景。

## 发布检查

```bash
bin/pmw-build-plugin
bin/pmw-gen-skill-docs check
bin/pmw-eval run
bin/pmw-version --json
```
