# product-agent-handoff

Produce delivery assets without false certainty.

## Read first

1. `../product-agent-shared/references/language-and-localization.md`
2. `../product-agent-shared/references/product-agent-readiness.md`
3. `../product-agent-shared/references/product-agent-gotchas.md`
4. `../product-agent-shared/references/artifact-flow.md`

## Outputs

- Product background and value.
- Product solution and feature description.
- Interfaces, data sources, tracking, experiment standards, and gaps.
- Pending decisions and non-fiction boundaries.

## Gotchas

- Do not invent interfaces, data, tracking, or acceptance criteria.
- If prototype-dependent delivery lacks review, state the risk or return to review.
- Keep unknowns as `待补充`, not as false commitments.
