# PMWorkspace v0.1.31

## 关键变化

- 新增 P0 入口守卫：`pmw-trigger-guard` 会在 PMW / AI 产品工作站 / 方案及原型 / 汽车之家独号转化等信号命中时先判断是否必须由 PMW 接管。
- 禁止普通 fallback：PMW 命中后，如果 runtime 或专用动作未接管，必须停止并说明阻断，不能继续读数据出方案、写 HTML 线框或直接调用 imagegen。
- 强化插件触发文案：Codex plugin listing 明确要求先通过 trigger guard 和 controller，避免“插件触发但工具不可见，所以继续普通方案输出”的旁路。
- 增加 imagegen 前置许可：`pmw-image-preflight assert-imagegen` 要求单图 `image_permit_id` 已签发且匹配当前 run / task / revision / 方案 / 屏幕，才允许写 image-2 prompt 或调用 imagegen。
- 新增 P0 回归 eval：覆盖 trigger guard、no generic fallback、imagegen-before-permit 三个入口前硬约束。
