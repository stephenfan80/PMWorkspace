# AI 产品工作站 / PMWorkspace v0.1.15

本版本新增 PMW 自身的版本身份入口，让本地 source、Codex plugin 和更新源对比有统一说法。

## 变化

- 新增 `bin/pmw-version`：输出 `VERSION`、`REVISION`、`VERSION@revision`、安装宿主、plugin version、远端版本 URL 和 GitHub repo URL。
- `bin/pmw-version --json` 支持机器读取，方便 agent / eval / 发布脚本检查。
- `bin/pmw-version --check` 会额外调用 `pmw-update-check --force`，用于和 GitHub 更新源对比。
- 明确版本概念：根目录 `VERSION` 是 PMW 产品 / 插件版本；`REVISION` 是插件打包源码提交；业务产品简报 `v1/v2` 不是 PMW 工具版本。

## 发布检查

```bash
bin/pmw-version
bin/pmw-gen-skill-docs check
bin/pmw-eval run
bin/pmw-build-plugin
```
