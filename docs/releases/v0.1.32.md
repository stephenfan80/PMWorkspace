# PMWorkspace v0.1.32

## 关键变化

- 修复新项目首次使用 PMW 的入口缺口：新增 `pmw-install-global-guard`，把 PMW 全局入口守卫写入 `~/.codex/AGENTS.md`。
- `pmw-upgrade --host codex-plugin` 会默认安装 / 刷新全局 guard，确保新电脑、新账号、新项目在没有项目级 `AGENTS.md` 时也先运行 `pmw-trigger-guard`。
- 全局 guard 明确要求命中 `AI 产品工作站`、`PMWorkspace`、`PMW`、`方案及原型` 或汽车之家 / 独号 / 线索 / 转化率等信号时，先运行 `pmw-trigger-guard`，再运行 `pmw-controller intake`。
- PMW runtime 未接管时必须停止，不能退回普通产品方案、数据分析出方案、HTML 线框或 imagegen 出图。
- 新增 P0 回归 eval：`p0-global-guard-installed`，覆盖新项目首次运行时不能只依赖项目 `AGENTS.md` 的问题。
