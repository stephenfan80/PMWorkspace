# PMWorkspace v0.1.29

## 关键变化

- 删除产品工作流里的轻量旁路模式，只保留 `全新功能` 和 `已有功能迭代` 两条产品路径，并统一进入深度产品对齐。
- `pmw-controller` 成为运行时路径裁判：新工具表述叠加业务指标优化时先返回 `D_REQUIRED`，明确已有/线上/迭代信号时改判为已有功能迭代并要求视觉基线。
- 出图许可收紧为唯一的 `ALLOW_IMAGE_PROMPT`；方向选择、方案 A/B/C、候选简报和旧产物都不能放行 image-2。
- 更新 `$pm-workspace`、`$pm-autoplan`、`$pm-brief`、`$pm-prototype-shotgun` 等 skill 契约和 PMW 首页文案，统一“先对齐，再出图，最后交付”。
- 更新 eval fixtures，覆盖当前 task revision、产品路径确认、旧产物不可放行和无 quick mode 的回归场景。
