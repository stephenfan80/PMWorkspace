# AI 产品工作站 / PMWorkspace v0.1.12

## Summary

This release updates the Codex plugin listing name to **AI 产品工作站** while keeping `PMWorkspace` as the repository, package, and `$pm-workspace` skill entrypoint.

## Highlights

- Renames the Codex plugin display name to `AI 产品工作站`.
- Keeps `pmworkspace` as the stable plugin package identifier.
- Adds Chinese and English search aliases, including `AI 产品工作站`, `AI产品工作站`, `ai-product-workstation`, and `PMWorkspace`.
- Updates plugin default prompts to use the public-facing plugin name.
- Adds a top-level Codex Plugin Beta install section to both README files.

## Install

Public Codex plugin users should update from Codex `Plugins` once the plugin is listed.

GitHub beta users can install or update with:

```bash
git clone https://github.com/stephenfan80/PMWorkspace.git
cd PMWorkspace
bin/pmw-upgrade --host codex-plugin
```

Legacy skill users can update with:

```bash
bin/pmw-upgrade --host codex
```

## Verification

Run before publishing:

```bash
bin/pmw-build-plugin
bin/pmw-gen-skill-docs check
bin/pmw-eval run
```
