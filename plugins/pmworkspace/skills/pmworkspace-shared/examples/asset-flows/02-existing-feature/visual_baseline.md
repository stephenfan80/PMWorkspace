## 必须保留区域

- 状态栏和顶部导航。
- 账号信息模块。
- 当前订阅名称、价格、到期时间。
- 依法取消入口。
- 底部安全区和系统返回手势区域。

## 可修改区域

- “暂停”和“取消”的说明模块。
- 主要按钮组的顺序和文案。
- 取消后的状态说明。
- 结果页的信息层级。

## 不可压缩项

- 取消入口必须在首屏或原位置附近可见。
- 当前订阅状态和生效时间不能被弱化。
- 不得用弹窗、倒计时、长问卷或隐藏入口拖慢取消。

## 视觉约束

- 沿用生产页字号密度和按钮样式。
- 不引入营销插画、大面积渐变或独立品牌风格。
- 新增说明模块要像生产功能的一部分，不像活动运营卡片。
