参考资产策略：不适用生产截图；保留 `visual_baseline` 资产位，让 PRD 明确视觉与交互基线来自产品判断而非真实页面

## 基线结论

本样例没有生产截图。原型可使用 `standard_first_screen`，但必须保持“先给预览，再留联系方式”的价值交换顺序，不能画成营销落地页或强销售表单。

## 视觉约束

| 字段 | 示例值 |
|---|---|
| 参考像素尺寸 | 不适用 |
| 目标画布 | iPhone 17 竖屏 `402 x 874` |
| 画布模式 | `standard_first_screen` |
| 生成模式 | `image-2 single image` |
| 设计系统来源 | PMW 默认移动端转化流程基线 |

## 保留边界

- 首屏先说明课程适合谁，再出现手机号提交。
- 试听片段只能表示片段预览，不能像完整课程授权。
- 可约时间只能表示参考时段，不能承诺已锁定老师。
- 结果页必须解释预约状态和等待边界。

## 可探索区域

- 课程预览、可约时间、手机号输入的先后顺序。
- 等级匹配题是前置、后置还是可跳过。
- 结果页如何表达“已提交但未确认”。

## 不可虚构边界

- 不展示老师即时确认、自动匹配老师、学习效果承诺。
- 不展示付款、证书、完整课程授权。
- 不引用真实老师照片、真实学员评价或内部排班数据。
