# PMWorkspace v0.1.30

## 关键变化

- 强化 controller 硬约束：`pmw-controller next --json` 暴露正式 workflow stage、下一技能、用户可见动作和 `can_write_brief` / `can_register_prototype_units` / `can_issue_image_permit` / `can_handoff` 能力位。
- 收紧当前任务新鲜度：旧 brief、旧 prototype-board、旧 review 和历史项目默认只能作为 `candidate_context`，必须经用户确认沿用并重新 stamp 当前 run / task / revision 才能放行。
- 增加确认质量校验：`autoplan`、`product_direction`、`strategy`、`brief`、`adopt_history` 等确认不能只写“已确认”，必须记录本轮判断、证据边界和关键字段。
- 引入 image-2 一次性出图许可证：正式图片登记必须绑定 `image_permit_id`，无 permit 的图片只能作为普通对话附件或 legacy audit，不进入 PMW 正式原型产物流。
- 调整 P2 流程顺序：已有功能缺线上 / 视觉基线时，允许先进入产品方向审查和策略审查；缺基线仍会在写已对齐 brief、登记原型或出图前硬阻断。
- 增强交付前 controller gate：`handoff` preflight 除 Product Readiness Dashboard 外，还会核验当前 revision 的 `prototype_manifest` 和 `prototype_review=可通过 / 可交付`。
- 前移 AutoDesign 决策：命中汽车之家 / 独号 / 线索 / 询价 / 查价等信号时，入口 / 自动评审阶段就暴露设计规范 D，默认推荐汽车之家 AutoDesign。
