# AI 产品工作站 / PMWorkspace v0.1.26

本版本修复 PMW 执行边界：流程规则不只写在 skill 和 dashboard 里，也在正式产物写入脚本层落地，避免 Agent 或手工命令绕过产品发现、简报确认、出图准备度和交付准备度。

## 变化

- `confidence=assumed` 不再计入已确认产品发现事实，只有 `confirmed` 可以支撑已对齐简报。
- 泛化 `decision` 不再自动算作方向性 D，必须像真实 PM 拍板一样有 D / 拍板 / 取舍等明确语义。
- `pmw-log prototype` 和 `pmw-log handoff` 写正式产物前强制通过 readiness；过程记录仍可用 `--draft` 保存。
- `pmw-artifact add` 增加正式产物守门，直接登记 `product_brief` / `prototype_manifest` / `product_design_doc` / `handoff` 也不能绕过。
- 待确认或草稿产物不能把下一技能指向正式原型、复审或交付链路。
- 新增 `formal-artifact-exit-gates` eval，覆盖假设当事实、泛化 decision 当 D、绕过 readiness 直接写产物等场景。
