# handoff：截图迭代说明 - 试听报名表单

交付类型：设计修改说明 / 局部交付更新
上游来源：`product_brief.md`、`visual_baseline.md`、`prototype_manifest.md`、`prototype_review.md`
交付结论：可更新设计稿；不改变 PRD 范围。

## 本轮改动

- 删除表单页红框解释模块。
- 保留手机号输入和主按钮。
- 保留隐私 / 协议入口。
- 结果页补足提交状态和下一步说明。

## 不变项

- 目标仍是降低试听报名前的阻力。
- 主按钮仍代表提交手机号，不代表预约已成功。
- 不新增字段、不新增后端能力、不新增客服或老师承诺。

## 功能说明

| 模块 | 改动 | 交付状态 |
|---|---|---|
| 表单解释模块 | 删除 | 可交付 |
| 手机号输入 | 保留 | 可交付 |
| 主按钮 | 保留，文案不扩大承诺 | 可交付 |
| 结果页状态说明 | 补充下一步和等待边界 | 可交付 |

## 验收边界

- 表单页首屏只保留必要输入和主动作。
- 删除解释模块后，页面不能出现明显空白断层。
- 结果页不能写“预约成功”，除非接口返回已预约成功。
- 隐私 / 协议入口必须保留。

## 待补充项

1. 结果页状态枚举：已提交、已预约、需人工确认、提交失败。
2. 手机号提交失败时的错误文案。
3. 是否需要短信验证码，本轮未纳入。
