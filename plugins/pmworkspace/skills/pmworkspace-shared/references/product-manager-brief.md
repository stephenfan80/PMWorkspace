# 产品简述 / 产品简报模板

产品简述 / 产品简报是出图前用于对齐“真实问题是什么、证据状态如何、为谁做、当前替代和损失是什么、选中路径和本周期验证是什么”的短版业务简报。它不是会议纪要，也不是最终产品设计文档。

## 推荐结构

## 最佳实践压缩原则

- Productboard 类产品简报强调问题、目标用户、当前状态、成功标准和约束。
- Shopify 类产品简报强调用户痛点、市场 / 竞品、目标受众和 KPI。
- Product discovery / customer discovery 强调先理解用户过去行为、当前替代和真实痛点，再讨论方案。
- 公开最佳实践只能作为 `竞品 / 行业做法` 与 `可借鉴原则`，不能覆盖本轮截图、数据、用户回答、反指标或不可虚构项。

## 用户可见与内部审计

用户可见业务简报必须包含产品作业卡、真实问题、证据状态、目标用户、当前替代 / 损失、选中路径、范围模式、本周期验证、主目标、反指标、不可虚构项、原型范围和待验证项；这些不是隐藏审计字段，避免旧链路把关键判断藏进支持信息。

内部审计继续保存 run、路径、门槛、事实 / 假设边界、Zoon 状态、Product Readiness Dashboard 和产物流动。默认不把本地路径、run_id、token、ownerSecret、未脱敏截图内容或 Zoon 私密正文写入业务简报。
