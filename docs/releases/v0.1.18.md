# AI 产品工作站 / PMWorkspace v0.1.18

本版本修复产品作业卡运行时体验：不再把多个产品发现缺口压成一个“最大缺口”作业，而是输出关键缺口队列、产品作业队列、PMW 产品建议和 PMW 信息架构建议。

## 变化

- `pmw-discovery-gate` 输出结构化 `gap_queue_items`，每个缺口都包含产品建议、信息架构建议和用户作业。
- `pmw-dashboard status` 默认展示当前主阻断、关键缺口队列、产品作业队列、PMW 产品建议、PMW 信息架构建议和当前 Q / D。
- 修复“产品作业：产品作业：”“PMW 建议：PMW 建议：”这类重复前缀。
- 清理产品简报模板里的重复用户可见字段说明，强化产品作业卡作为简报前对齐入口。
- 新增 eval 覆盖产品作业队列、双建议字段和重复前缀防回归。
