# AI 产品工作站 / PMWorkspace v0.1.13

This release fixes local Codex plugin discovery before the public plugin listing is approved.

## Highlights

- Adds repo-root `.agents/plugins/marketplace.json` so the repository can be added as a Codex local marketplace.
- Updates `pmw-upgrade --host codex-plugin` to use `codex plugin marketplace add/upgrade` when the Codex CLI is available.
- Keeps the previous `~/.agents/plugins` fallback package for local agent-compatible installs.
- Documents that users must switch the Plugins filter from `Built by OpenAI` to `All` when testing the local marketplace package.
- Extends update detection to recognize Codex plugin cache installs under `~/.codex/plugins/cache`.

## Beta Install

```bash
git clone https://github.com/stephenfan80/PMWorkspace.git
cd PMWorkspace
bin/pmw-upgrade --host codex-plugin
```

Then restart Codex, open `Plugins`, switch the filter to `All`, and search `AI 产品工作站` or `PMWorkspace`.

## Direct Marketplace Add

```bash
codex plugin marketplace add stephenfan80/PMWorkspace
```

Public marketplace search will only work after the plugin is accepted into the Codex plugin directory.
