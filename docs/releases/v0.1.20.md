# AI 产品工作站 / PMWorkspace v0.1.20

本版本修复版本升级系统：每个 skill 运行前都走快速更新检查；发现远端有新版本时先询问用户是否更新；执行升级时先清理 PMWorkspace 旧安装目录，再写入最新版本，避免旧文件残留。

## 变化

- `pmw-update-check` 新增 `--quick`：复用短缓存，使用短超时读取远端 `VERSION` 和插件包 `REVISION`，避免每次运行都做慢速检查。
- 所有 `$pm-*` skill preamble 改为 `pmw-update-check --quick`，并在出现 `UPGRADE_AVAILABLE` 时输出提示，要求先询问用户是否执行 `UPGRADE_COMMAND`。
- `pmw-upgrade` 在安装前删除所选 host 的旧 PMWorkspace 安装目录，确保本地只保留最新版本内容；不会删除 `~/.pmworkspace` 项目状态、产品简报、原型或交付资产。
- 更新 `update-workflow.md` 和 README，明确快速检查、用户确认、`auto_upgrade` 和升级清理边界。
- 新增 eval 覆盖快速检查、缓存命中、升级清理旧目录。

## 发布检查

```bash
bin/pmw-gen-skill-docs check
bin/pmw-eval run
bin/pmw-build-plugin
```
