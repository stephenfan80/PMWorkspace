# prototype_review：课程试听报名流程

复审目标：判断哪个转化路径适合作为 PRD 主方案，并识别不可写入验收的能力缺口。

## 总 verdict

可通过。推荐以 **方案 A：先给预览** 作为主路径，保留方案 B 的可约时间模块作为辅助信息，不采用方案 C 的等级题作为必填。

## 策略复审

- A 直接回应用户在留资前的最大疑虑，价值交换最清晰。
- B 对真实预约有帮助，但如果放在第一步，会让页面像排班工具。
- C 有助于提高线索质量，但必填会伤害转化，应设为可选或后置。

## 信任 / 风险复审

- 通过：A 没有承诺学习效果。
- 需保留：试听片段范围必须清楚，不能像完整课程。
- 禁止：结果页不能写“老师将立即联系”。

## 设计系统复审

- 通过：移动端信息层级合理，主 CTA 清楚。
- 需修正：不要使用过度营销化倒计时、名额紧张或夸张证明。

## 数据可行性复审

- 已具备：课程等级、课程大纲、试听片段。
- 待确认：老师可约时间接口、预约状态枚举、等级题是否必填。
- 不可写入验收：自动老师匹配、即时确认、证书或学习效果承诺。

## 交付建议

进入 `$pm-handoff` 输出精简 PRD。PRD 主方案采用 A，B 作为辅助模块，C 作为可选增强或实验项。
